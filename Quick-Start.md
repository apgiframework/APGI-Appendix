# APGI Appendix – Quick Start

This guide gets you up and running with the APGI Appendix app in a few minutes.

---

## 1. First Launch Overview

When you open the app, you'll typically see:

- **Sidebar Navigation**
  - Main navigation with sections:
    - `Interactive Timeline`
    - `Neuromodulators`
    - `Glossary`
    - `Bibliography`
    - `Methodology`
    - `Psychiatric Disorders`

- **Main Content Area**
  - Displays the currently selected module (e.g. timeline, glossary entry, or neuromodulator detail).

Use the **sidebar** to move between major sections.

---

## 2. Core Features in 60 Seconds

- **Interactive Timeline**
  - Pan and zoom through the timeline with standard touch gestures.
  - Tap an event to open more details.
  - Use filters to focus on specific eras, topics, or categories.

- **Neuromodulator Effects**
  - Browse a list of neuromodulators.
  - Tap a neuromodulator to see:
    - Description
    - Effects
    - Associated systems or pathways
    - Relevant references

- **Glossary**
  - Search or browse key terms.
  - Tap a term for a concise definition and links to related content.

- **Bibliography**
  - View references supporting the content.
  - Use search to find citations by author, year, or keyword.

---

## 3. Basic Navigation

- **Sidebar navigation**
  - Tap an item to switch sections.
  - Selected section is highlighted.

- **Back / Close actions**
  - Use the **Back** button or swipe gestures to dismiss detail views.
  - On iPad, details often appear side‑by‑side with lists.

- **Search**
  - Use the search bar in Glossary, Bibliography, or other lists:
    - Tap into the field.
    - Type part of a term, author, or keyword.
    - Results filter automatically.

---

## 4. Customization & Settings

The app uses the APGI color palette for consistent visual cues across all sections. Access options from the **Sidebar** navigation.

---

## 5. Getting Help

- **In‑App Content**
  - Each section includes contextual information and descriptions.
  - Start with the **Interactive Timeline** for chronological overview.
  - Use **Glossary** for term definitions.
  - Consult **Bibliography** for detailed references.

For more detail on all features, see **User-Guide.md**.
